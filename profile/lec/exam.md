# Вопросы для экзамена по Java

## Билет №1

**Теория:**
1. Перечислите примитивные типы данных в Java. Расскажите о явном и неявном приведении типов (type casting).
2. Понятие класса и объекта. Чем отличается класс от объекта? Приведите пример.

**Практика:**
Напишите метод, который принимает массив целых чисел и возвращает новый массив, содержащий только четные числа из исходного массива.

---

## Билет №2

**Теория:**
1. Чем отличается оператор `==` от метода `equals()` при сравнении объектов? Приведите пример.
2. Модификаторы доступа (`private`, `protected`, `public`, `package-private`). Объясните область видимости каждого.

**Практика:**
Напишите класс `Counter` с полем `int count`, методами `increment()` и `decrement()` и геттером `getCount()`. Реализуйте проверку: счетчик не может стать отрицательным (при попытке уменьшить ниже 0 выбрасывайте `IllegalArgumentException`).

## Билет №3

**Теория:**
1. Расскажите про управляющие конструкции в Java: условные операторы (`if-else`, `switch`), циклы (`for`, `while`, `do-while`), операторы `break` и `continue`.
2. Конструкторы. Правила написания конструктора. Что такое конструктор по умолчанию?

**Практика:**
Напишите метод, который принимает строку и возвращает `true`, если строка является палиндромом (игнорируя регистр и пробелы). Используйте цикл.

## Билет №4

**Теория:**
1. Массивы в Java: создание, инициализация, доступ к элементам, длина массива. Могут ли массивы изменять размер?
2. Наследование. Как наследуются поля и методы? Что такое `super`?

**Практика:**
Создайте класс `Animal` с полем `String name` и методом `makeSound()`, который выводит "Some sound". Создайте класс `Dog`, наследующий `Animal`, переопределите `makeSound()` для вывода "Woof!". В методе `main` создайте объект `Dog` и вызовите его метод.
