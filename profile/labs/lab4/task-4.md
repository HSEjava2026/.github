
# Практическое задание: Разработка системы управления персоналом (HRM Lite)

## 1. Общее описание

**Цель задания:** Закрепить навыки объектно-ориентированного программирования (ООП) и консольным вводом-выводом.

Вам необходимо разработать консольное приложение для управления данными сотрудников компании.

## 2. Архитектура приложения

Проект должен содержаться в пакете `ru.hse` и должен быть разделен на логические пакеты:

1. `model` — описание сущностей (POJO классы).
2. `service` — бизнес-логика приложения.
3. `presentation` — взаимодействие с пользователем через консоль.
- Main class - HrmApplication
---

## 3. Подробные требования к реализации

### Шаг 1: Создание модели данных (`Employee`)

Создайте абстрактный класс `Employee` со следующими полями:

* `Long id` — уникальный идентификатор (генерируется автоматически при создании сотрундика).
* `String name` — ФИО сотрудника.
* `String` position — конкретная должность (пример: java разработчик).
* `BigDecimal salary` — заработная плата.
* `LocalDate hireDate` — дата приема на работу.

Создайте класс `Task` 
* `Long id` — уникальный id задачи (присваивается при создании)
* `String taskName` — именование задачи
* `LocalDate startDay` — дата выдачи
* `LocalDate endDay` — дата окончания
* `State state`  — статус задачи

Класс `State` - enum со значениями:
IN PROGRESS, DONE

Создайте класс `Manager` <- `Employee` добавляющий поле `Programmer[] programmers`
Создайте класс `Programmer` <- `Employee` добавляющий поля `Task[] tasks` и `Grade grade`
где Grade - Enum со значениями: JUNIOR, MIDDLE, SENIOR


> **Важно:** Все поля должны быть приватными. Реализуйте геттеры, сеттеры, конструктор и метод `toString()`.

### Шаг 2: Бизнес-логика (`HRMService`)

Создайте сервис, который управляет процессами:

* Вывод информации о всех сотрудниках: ФИО, дата приема, должность, зп
* Вывод разработчиков определенного грейда
* Выдача списка задач по id сотрудника
* Выдача сотрудника по id задачи и ответственного менеджера
* Сотрудники с опытом более N лет
* задачи с просроченным дедлайном

### Шаг 3: Консольный интерфейс (`Reporter`)

В пакете presentatnion реализуйте метод `show` и в нем бесконечный цикл `while` с текстовым меню по задачам бизнес-логики.
При выводе информации о сотрудниках форматировать вывод по правилам:
Пусть salary будет выровнено по правому краю, десятичное значение имеет 2 знака после запятой.

### Шаг 4: Класс `HRMApplication`
Создайте `main` метод в классе и создайте N-сотрудников. Создайте и запустите экземплер Repoter с вызовом метода `show()`

## Функциональные требования

1. При работе разрешено использовать только стандарные классы библиотк Java
2. Использование Collection API запрешено
3. Создание сотрудников осуществляется исключительно в классе HRMApplication при старте приложения.
